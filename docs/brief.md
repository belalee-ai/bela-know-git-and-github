# 《文科生也能懂的 Git & GitHub》直播网页

这场约 90 分钟的小红书直播面向零编程基础的观众。主播全屏展示「Bela OS」粉色电脑桌面，以毕业论文 v7 为线索。六个节目各约 12–15 分钟，随时可以跳入任意一节。

| 节目 | 主播带观众做的事 |
| --- | --- |
| 1 · 论文时光机 | 输入一段论文、存档，再打开旧版本，看哪些字发生了变化。 |
| 2 · 平行宇宙 | 用对话引出分支，给大胆版存档。两条线改了同一句时，由弹幕选合并结果。 |
| 3 · 逛逛 GitHub | 同一篇探店稿改了标题和署名，只挑一处存档。依次点提交、推送和朋友拉取，看四栏里哪份稿变了。回到模拟仓库还能点六个热点，了解收藏、提问和投稿。 |
| 4 · 开源名人堂 | 推进 Git 和 Linux 的时间线，主讲 OpenClaw，再用 DeepSeek、996.ICU 和 GitHub 全站规模快闪收尾。 |
| 5 · AI 后悔药 | 让演示助手改好按钮、留下存档，再模拟一次改坏，现场恢复。用大白话比较三种撤销办法。 |
| 6 · 我的 28 次存档 | 分四章读 belalee-website 的真实提交，拿其中一条的编号看离线提问示例。模拟建仓时选公开或私有，看谁能读、谁有权修改，再选出要分享的 README 并提交。 |

## 直播画面

- 1920×1080 等比缩放。右下 400×300 留给摄像头。主要标题至少 56px、教学正文至少 28px。观众主屏含任务栏、节目和回顾的可见中文合计不超过 80 字，主讲提词卡单独在副屏阅读。
- 每节第一屏先照顾刚进来的观众。桌面和节目旁常驻静音的 30 秒循环。支持减少动态效果。
- 1–6 切节目，0 或 Esc 回桌面，左右键逐步讲。L 放大循环，T 查词，Q 做本节小测。N 打开独立提词卡。
- 用本地素材与固定日期的数据快照。双击 index.html 即可运行，直播现场无需安装、联网、登录或打开终端。
- 轻量主播贴纸写「李贝拉Bela · 文科生学 AI 编程」。OpenClaw 用于说明开源协作。提词卡与观众画面分别打开。

本次按 Antigravity 最后的网页构建任务书交付。网页内的循环是这次演示的一部分，独立 MP4 属于早期直播总体规划。公开仓库只收录页面使用的已授权素材。
