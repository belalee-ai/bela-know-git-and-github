# 《文科生也能懂的 Git & GitHub》直播网页

这场约 90 分钟的小红书直播面向零编程基础的观众。主播全屏展示「Bela OS」粉色电脑桌面，以平实大白话、成体系地讲清 Git 与 GitHub 的完整底层逻辑，并在结尾用「干中学」三阶清单消除学习焦虑。六个节目各约 12–15 分钟，随时可以跳入任意一节。

| 节目 | 主播带观众做的事 |
| --- | --- |
| 1 · 认识 Git 与诞生记 | 从「7 个最终版」和「AI 改崩找不回」痛点切入，讲清 Git 是版本管理系统，推进 Linus 10 天写出 Git 的时间线，引出 2008 年 GitHub 登场。 |
| 2 · AI 时代为何必学 | 讲透 AI 时代必学 Git 的 4 个理由，现场模拟 AI 改坏页面一秒回退，对比三种后悔药（Discard / Reset / Revert）与指挥 AI 的人话口令。 |
| 3 · 四个区域与周转 | 拆解工作区、暂存区、本地仓库（`.git`）、远程仓库（GitHub），用交互流转沙盘演示 6 个核心命令周转，再动手体验带短哈希与红绿 Diff 的完整存档。 |
| 4 · 分支开发与合并 | 用对话引出主线 `main` 与试改分支 `feature`，看分支独立存档如何保护主线；两边改撞车触发冲突（Conflict）时，由弹幕投票拍板合并。 |
| 5 · 安装与联动 GitHub | 介绍开工准备三件套，重点演练 `.gitignore` 忽略密钥 `.env` 的安全红线，再分两条路径互动模拟「本地推上 GitHub」与「克隆到本地双向同步」。 |
| 6 · GitHub 与真实记录 | 一页拆解 GitHub 仓库 7 大热点，串联开源协作 4 步流（Fork → PR → Merge）与 OpenClaw 等案例，翻开 `belalee-website` 28 次真实提交，最后用「普通人懂到哪就能直接开干」三阶卡压轴收官。 |

## 直播画面

- 1920×1080 等比缩放。右下 400×300 留给摄像头。顶部常驻「刚进来的朋友」一句话总结，底部保留完整工具标签（术语翻译机、弹幕小测、提词卡）。
- 桌面和节目旁常驻静音的 30 秒循环。支持减少动态效果。
- 1–6 切节目，0 或 Esc 回桌面，左右键逐步讲。L 放大循环，T 查词（24 词带分类与实战提示），Q 做本节小测，N 打开独立提词卡。
- 用本地素材与固定日期的数据快照。双击 `index.html` 即可运行，直播现场无需安装、联网、登录或打开终端。
- 轻量主播贴纸写「李贝拉Bela · 文科生学 AI 编程」。OpenClaw 仅用于说明开源协作。提词卡与观众画面分别打开。
